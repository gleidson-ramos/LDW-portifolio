# 💼 Portifólio
Exemplo de um simples portfólio desenvolvido com React, apresentando uma aplicação web organizada em componentes e páginas para exibição de informações e projetos.

## ✨ Funcionalidades
- Interface web desenvolvida com React
- Navegação entre páginas utilizando React Router
- Componentização da aplicação
- Utilização de ícones através do React Icons
- Layout responsivo para apresentação do portfólio


## 🛠️ Tecnologias
- JavaScript
- React (DOM / Router / Icons)

## 📋 Pré-requisitos
Antes de executar o projeto, certifique-se de ter instalado:
- Node.js
- npm

## ▶️ Uso

Para iniciar o projeto em ambiente de desenvolvimento:
```bash
npm start
```
Após iniciar o servidor, acesse:
```bash
http://localhost:3000
```

## 📄 Sobre o Projeto
O portifolio foi desenvolvido como uma atividade para a disciplina Laboratório de Desenvolvimento Web. O projeto utiliza componentização, navegação entre páginas e bibliotecas do ecossistema React para construir a interface da aplicação.
